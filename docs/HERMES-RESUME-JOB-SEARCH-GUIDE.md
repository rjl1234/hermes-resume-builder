# How to Use the Optimized Resume + Job Search Profile in Hermes Desktop

## Step 1: Create the Profile

In Hermes Desktop:

1. Click **"New profile"** (from the left sidebar)
2. Fill in:
   - **Name:** `resume-job-search`
   - **Clone from:** `default`
   - **SOUL.md:** Copy-paste the entire content from `hermes-resume-job-search-optimized.prompt.md`
3. Click **"Create profile"**

## Step 2: Start a New Session

1. Click **"New session"** (top of left sidebar)
2. Make sure the profile dropdown shows: `resume-job-search`
3. You're ready to go

## Step 3: Use One of These Opening Prompts

### Option A: Build Resume + Find Jobs (Most Popular)
```
Build my resume and find me jobs. First, ask me about my background.
```

**What happens:**
1. Agent asks for your work history, education, skills, projects
2. Creates a structured resume
3. Asks what job titles to search for
4. Searches all platforms
5. Matches your resume to the top opportunities
6. Shows match scores and recommendations

### Option B: Search Jobs First
```
Find me [job title] jobs in [location]. Then match them to my resume.
```

**Example:**
```
Find me Product Manager jobs in San Francisco. Then match them to my resume.
```

**What happens:**
1. Agent searches all platforms
2. Shows top 10 matching jobs
3. Asks for your background
4. Creates your resume
5. Matches to the jobs
6. Shows scores

### Option C: Optimize for Specific Job
```
I found this job. Help me apply. [paste job description]
```

**What happens:**
1. Agent analyzes job requirements
2. Asks for your background
3. Creates your resume
4. Shows match score
5. Customizes resume for this job
6. Generates cover letter
7. Offers to track application

### Option D: Quick Resume Build
```
Create a resume for a [job title] with my background. Ask me my details.
```

**Example:**
```
Create a resume for a Senior Software Engineer. Ask me my details.
```

## Step 4: Follow the Agent's Questions

The agent will typically ask:

**For Resume Building:**
- What's your full name?
- Current or target job title?
- Years of experience?
- What are your top 5 skills?
- What's your biggest achievement (with metrics)?
- Where did you go to school?
- Any certifications or awards?
- Any side projects or portfolio?

**For Job Matching:**
- What job titles interest you?
- What locations?
- Full-time or open to contract?
- Remote work required?
- Salary expectations?
- Any company preferences?
- Industry preferences?

## Step 5: Review Results

### When Building Resume
The agent will show:
- Your resume in a readable format
- Summary of sections
- ATS score
- Suggestions for improvement

### When Matching to Jobs
The agent will show:
- Top 10 jobs ranked by match score
- Job title, company, location, salary
- Match score (0-100%)
- Your strengths for each role
- Missing skills with learning timeline
- Recommendation: Apply / Apply & Prepare / Build Skills First

### When Optimizing for Specific Job
The agent will show:
- Match score for this job
- Your relevant achievements
- What's missing
- Customized resume (tailored for this job)
- Customized cover letter
- Next steps (apply, track, follow-up)

## Best Workflows

### Workflow 1: Complete Job Application (Recommended)

```
1. "Build my resume and find me product manager jobs in San Francisco"
   ↓
2. Provide your background info as agent asks
   ↓
3. Agent shows top 10 matching jobs with scores
   ↓
4. You pick your top 3 choices
   ↓
5. Agent customizes resume for each
   ↓
6. Agent generates cover letters
   ↓
7. You apply to all 3
   ↓
8. Agent tracks applications and suggests follow-ups

```

```
   ↓
```

### Workflow 3: Specific Job Application

```
1. "I found this job, help me apply" [paste job description]
   ↓
2. Agent analyzes and asks about your background
   ↓

   ↓
```

## Keyboard Shortcuts

- **Ctrl+N** - New session
- **Ctrl+L** - Clear chat
- Type and press **Enter** - Send message

## Tips for Best Results

1. **Be Detailed** - The more info you give, the better the resume
2. **Use Metrics** - Include numbers: increased revenue by 30%, led team of 5
3. **Be Honest** - Never exaggerate; agent will call it out
4. **Pick Your Top Matches** - Don't apply to everything; focus on best 3-5 fits
5. **Customize for Each Job** - Let agent tailor resume and cover letter
6. **Track Applications** - Use agent to follow up after 2 weeks
7. **Act on Feedback** - If match score is low, work on missing skills

## Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| Agent not using your profile | Select profile from dropdown before chatting |
| Resume looks incomplete | Provide more details on achievements and projects |
| Job match score is low | Missing skills listed; consider learning them or targeting different roles |
| Can't find specific job board | Use search_jobs_all_platforms to search across all at once |
| Want to save your resume | Export as PDF using agent tool |
| Need to update resume later | Start new session, upload old resume, ask to update it |

## When You're Ready to Apply

After customizing resume and cover letter:

1. Copy the customized resume
2. Copy the cover letter
3. Go to the job posting
4. Paste resume and cover letter in application
5. Tell agent: "I applied to [company]" - agent will track it
6. Agent suggests: "Follow up in 2 weeks if no response"

That's it! You're ready to start using Hermes Resume Builder + Job Search.
